- `pyproject.toml` 使用 hatchling 作为构建后端，声明包名 jirin、Python ≥3.11 以及 LangGraph/LangChain/LiteLLM/ChromaDB/sentence-transformers 等核心依赖；通过 `[project.scripts]` 将 `jirin` CLI 命令绑定到 `src/jirin.cli.main:app`（Typer），并通过 `[tool.hatch.build.targets.wheel] packages = ["src/jirin"]` 指定源码位于 `src/` 布局。
- `config/settings.example.toml` 为只读模板，`config/settings.toml` 为实际生效的运行时配置，二者结构一致，包含 `[llm]`（provider/model/api_key）、`[embedding]`（local/openai）、`[knowledge]`（静态知识库路径与相似度阈值）、`[storage]`（cases/memory/vector_db 目录）和 `[export]` 五个顶层段。
- `data/{cases,exports,memory}/.gitkeep` 仅保留目录骨架，真实 JSON 文件由运行期生成并被 `.gitignore` 排除；`config/settings.toml` 同样被忽略以保护密钥，开发者需从 example 复制并填写。
- 工具链在 pyproject 中内联：ruff（E/F/I/N/W 规则集）、pytest（asyncio auto 模式）、mypy（strict=true），均面向 py311。
